# 改裝規劃室

這是以公開資料整理而成的改裝車選配參考站。選好車款後，可依改裝方向比較各品牌改裝品、參考價與合法性提醒，並整理成可分享的清單。

網站為靜態頁面（`index.html`、`css/`、`js/`、`data/`），使用相對路徑，不需要建置。

## 請注意

- 法規與合法性提示僅供參考，不代表保證合法或違規。實際規定請以監理機關與合格廠商的最新說明為準。
- 部分連結為蝦皮分潤連結，不影響購買價格。
- 價格皆為參考價，實際價格以店家為準。

## 部署

推送到 `main` 後，由 GitHub Actions 部署到 GitHub Pages。請在儲存庫 Settings > Pages 將來源設為 GitHub Actions。
